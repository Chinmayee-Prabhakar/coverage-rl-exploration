# What this archival release deliberately does not contain

This project is **not a working reproduction package**. A historical study can be candidly documented without distributing code that includes copied components with unclear rights or results that cannot be traced to a validated run.

## Included

- Original explanatory text prepared for this archival release.
- Source-provenance references and known licensing boundaries.
- An evidence-aligned account of attempted methods, unsuccessful results, and reproducibility limitations.

## Excluded

- The complete historical working directories and all copied third-party source.
- Files derived from Philip Tabor's learner and training scaffold, for which no explicit redistribution license was identified.
- Modified OpenAI MPE source, even though its original license permits reuse under MIT conditions; not necessary to communicate this project accurately.
- Autoencoder Python files and scratch experiments without confirmed personal file-level provenance.
- Checkpoints, archived Python environments, temporary ZIPs, generated data and training logs without traceable run manifests.
- Demonstration GIFs originally made by upstream authors, and other visualizations without a verified link to local runs.
- Local disk paths, private machine details, or source archive inventory containing personal directories.

## Checks performed on the staged package

1. Compared all included files against a deliberate documentation-only allowlist.
2. Searched for references to local absolute machine paths, secrets, and binary/media/code file types.
3. Verified the ZIP package contains only Markdown and simple Git configuration text.
4. Verified no third-party source code, attributed images, checkpoints, or source archive is present.

This is **a scoped copyright/provenance risk review, not legal advice or an absolute legal guarantee**. Existing source archives and previous third-party permissions were not independently certified, and no assertion about rights over hypothetical future additions is made.
